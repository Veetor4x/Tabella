# tabella wordmark concepts, round 2 (not applied)

Six concepts, each shown on ink with an app icon. See `comparison-sheet.png`.

- **Typeface:** League Spartan ExtraBold, Copyright 2020 The League Spartan Project Authors, SIL Open Font License 1.1
  (free for commercial use; licence text in `LeagueSpartan-OFL.txt`). The letters are the font's real outlines converted
  to paths, then cut and combined.
- **Regenerate:** `npm i opentype.js @fontsource/league-spartan && node generate.cjs <output folder>`.
- The cuts use SVG clip paths and masks, so the files are concept artwork. The chosen one should be flattened to
  plain paths before it is used as a logo.
